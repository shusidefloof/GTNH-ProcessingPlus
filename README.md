# GT:NH Processing+

A GregTech: New Horizons addon that adds new multiblocks and long processing chains based on real chemistry, then ties them into the pack's progression. It's still in alpha, so expect unfinished parts and recipe changes.

Built for GTNH 2.9.0. Grab the jar from [Releases](https://github.com/shusidefloof/GTNH-ProcessingPlus/releases) and drop it in `mods`. Make sure to backup up your world first.

## What it adds

- **16 new multiblocks**, including a photolithography chamber you fill with singleblock machines, a cryogenic separation column and a supercritical dryer
- **Photoresist from MV to UMV**, and circuit boards are now made with it. Its one long processing chain spanning each tier starting from MV.
- **New material chains** like carbon fiber, nylon, ceramics, aerogels, Vibranium, Unobtanium, Neptunium and Promethium
- **Minor changes in recipes for GTNH Components** from IV and up, using the materials above
- **New cables**, including an Unobtanium superconductor
- **A quest line** that walks you through each tier and processing chain

## Some of the machines

- **Spectral Photolithography Chamber:** fill its bays with singleblock machines in the right order to make circuit boards, putting them in the wrong order gets you Scorched Circuit Boards.
- **Cryogenic Separation Column:** separates air and other gases using Freon R-12. Random Freon losses create a debt you have to repay on the next run, or it stops.
- **Supercritical Dryer:** dries gels into aerogels in three stages that you manage through its Input Hatch.
- **Hybrid Phase Reactor:** a big fusion ring like reactor where you tune a frequency, and fatigue changes your output the longer you stay on one frequency.
- **Ceramic Reaction Vessel:** makes advanced alloys, and doubles as a much faster Alloy Blast Smelter.

## What changes in GTNH

- Circuit boards from Epoxy to Optical are made in the Spectral Photolithography Chamber
- IV hulls need RHEA cable, and ZPM hulls need Unobtanium cable
- ZPM components need Vibranium, and ZPM and up conveyors and robot arms need Nylon-6,6
- LuV and up assembly line recipes use hBN Lubricant
- UHV and up superconductors are made in the Cryogenic Annealing Cryostat

## Requirements

- Minecraft 1.7.10 and a GTNH / GT5U runtime.
- GTNH 2.9.0 stable
- Java 17/21/25 are tested

Download a normal player JAR from Releases, place it in the instance's modsfolder, and remove older copies. Do not install -dev, , -sources, or -apiartifacts.
This is an unofficial community addon.
